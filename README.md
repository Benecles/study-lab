# Study Lab

Small live experiments turning dense law-school study material into crafted,
animated, scroll-driven web pages instead of plain PDF/EPUB text — each piece
tests a different modern web technique on a real (but disposable/vehicle)
legal topic.

Live: see repo Pages URL once enabled.

See `VISUAL_CRAFT_NOTES.md` for the full working notebook: technique catalog,
bugs hit, open questions, and an honest R&D log.
